# ashare-quant 量化工作台

本地运行的 A 股公开行情 + 技术分析 + 公司基本面 + 条件选股 + 回测 + 模拟盘/自动交易/复盘桌面程序。PySide6 界面，数据存本机 SQLite，不需要账号。

**不含**：券商/同花顺下单、真单、加密货币、任何投资建议。带一个本机模拟盘用于练习与复盘，自动交易也只走模拟盘；数据回流默认关闭，开启后只上传脱敏后的回测/决策样本（见下文）。

## 一键安装（Windows，推荐）

**最省事**：下载 [`install-online.bat`](https://raw.githubusercontent.com/Gray2006/ashare-quant/main/install-online.bat)，双击。
它会自动查 GitHub 最新版本、下载、解压到 `%USERPROFILE%\ashare-quant`，
再建虚拟环境、装依赖、生成桌面快捷方式。全程只需要一个文件。

或者手动：

1. 下载仓库 ZIP，解压到一个**普通目录**（不要放 `C:\Program Files`，那里没写权限）
2. 双击 `install.bat`
3. 等 1~3 分钟（第一次要下载 PySide6 等依赖）
4. 桌面出现「量化工作台」，双击就能用

要求：Windows 10/11，已装 Python 3.10+（安装时勾选 “Add python.exe to PATH”）。
不需要管理员权限；装完 `config.json`、`data/` 都在解压目录里，卸载或换机直接拷走。

- 启动：`start.bat`，或桌面快捷方式；想看报错用 `start.bat --console`
- 卸载：`uninstall.bat`（只删 `.venv` 和快捷方式，配置/缓存/待上传样本都保留）
- 已装过再跑 `install-online.bat` 会提示「已经装过」，升级请走程序内「设置 → 检查更新」

## 回测口径（先看这段再看收益）

`quantlab/engine/backtest_core.py` 是买入价、成本、基准、判定的唯一出处：

| 项 | 口径 |
|---|---|
| 买入价 | **T+1 开盘**。龙虎榜、公告、财报都是盘后才有，T 日收盘买不到 —— 用收盘价算会把次日高开白送进去 |
| 成本 | 双边 0.16%（佣金 + 印花税 + 滑点） |
| 基准 | 同期全市场同口径平均。没有基准的「超额」不算数：一段下跌行情里任何策略都是负的 |
| 判定 | **按日聚合**的 t 检验 —— 同一天几十只票一起涨跌是相关的，当成独立样本会把 t 放大约 √只数 倍 |

## 这几条已经证否了

写在这里，省得后来的人重复踩：

**横截面 alpha**：45 因子等权 rank 扣费后跑不赢等权；beta 中性化后 t=−1.44。
判定规则是原始 t 和中性化 t 都要 ≥2 才算真 alpha。

**做T**：52 只 × 21 个交易日真实 5 分钟线，七组参数全部为负，组合日 t 在 −1.1 ~ −1.9。
亏损结构：完整一轮 558 笔净 +20.7 万，但「卖了没回补、收盘强平」184 笔净 −33.1 万。
胜率 96% 却亏钱，因为赢小输大。所以它只作为自动交易里的降成本动作，不是独立策略。

**游资跟买**：143 个非通道席位里只有 13 个样本够（n≥30 且天数≥10），
这 13 个反向 t≥2 的一个都没有（最高 1.95）。13 个里 10 个超额为负，
二项检验 p=0.092，方向一致但强度不够。5 个头部席位在 T+1 开盘买入后 5 日
超额 −1.2% ~ −5.5%，胜率 25% ~ 43%。

> 小样本的「显著」全是噪声：8 笔 3 天能算出 t=6.32，加样本门槛后全部消失。
>

> [`docs/五条线结论-2026-11.md`](docs/五条线结论-2026-11.md)。

## 手动安装（开发者）

```bat
git clone https://github.com/Gray2006/ashare-quant.git
cd ashare-quant
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py
```

首次运行生成：

- `config.json`：自选股、刷新频率、界面设置
- `data/quantlab.db`：行情缓存与历史 K 线

源码运行时这两个文件在仓库目录；打包版在 `%LOCALAPPDATA%\ashare-quant`。可用环境变量 `GRAY_HOME` 指定独立目录。

自检：

```bat
python run.py --check      # 依赖与关键页面能否实例化
python run.py --smoke      # 真建主窗口逐页切换(offscreen 下可用)
python tests/test_feedback_client.py   # 数据回流客户端(离线:脱敏/队列/地址校验)
python tests/test_factor_mine.py      # 因子挖掘(模板/IC/分层/组合回测/自动落盘)
python tests/test_factor_gp.py        # 遗传因子搜索(表达式树/样本外/搜索)
```

## 数据来源

只抓公开网页行情，不登录、不缴费、不伪装来源：

- 东方财富：全市场快照、K 线、资金流、龙虎榜、板块
- 新浪：股票列表、部分行情回退
- 腾讯：日线 / 分时回退

接口随时可能变；抓不到时页面会显示数据源状态，不会拿假数据顶上。境外接口在部分网络下不可达，属正常。

## 数据安全

- **凭据字段**：config.json 里的接口密钥 / 本机 token 会加密落盘：Windows 用
  DPAPI（绑定当前用户），其他平台用 `.field.key` 的 Fernet 密钥（权限 600），
  程序读写时透明还原。加密后的值带 `dpapi1:` / `fernet1:` 前缀。
- **本地数据保险箱**：程序不运行时，可以把 `config.json` 与 `data/` 打包成
  一个 AES-256-GCM 加密的 `.vault` 文件：

  ```bat
  python tools/secure_data.py status
  python tools/secure_data.py encrypt
  python tools/secure_data.py decrypt vault/backup-xxxx.vault
  ```

  口令用 scrypt 派生，忘了就解不开。运行中的 SQLite 仍是明文（换 SQLCipher
  要换驱动、迁移库，风险大），所以保险箱是「关机 / 备份 / 带走」时用的。

## 本机控制接口（默认关闭）

给脚本 / AI 代理操作**模拟盘**用的本地 HTTP 接口。默认**不启动**，因为它会开一个
本地监听端口，没人要求就不该默默开着。

**怎么开**：把 `config.json` 里的 `agent.enabled` 改成 `true`，重启程序。

- 只绑 `127.0.0.1`，不对外
- 必须带 `X-Token` 头；token 首次启动自动生成（32 字节随机）并加密落盘，
  也可用 `python -m quantlab.agent.server` 单独起
- 校验 Host / Origin，挡 DNS rebinding 与跨站写请求
- `agent.allow_live` 默认 `false`，只能动模拟盘

## 数据回流（可选，默认关闭）

目的：把公开用户回测/决策里的**比例型结果**汇总起来训练模型，改善默认参数和因子权重。
没有账号系统，不需要登录。

**怎么开**：设置页 →「数据回流」→ 勾选。首次勾选会弹窗说明发什么、不发什么。
地址和 key 已内置（`cloud_defaults.json`），不用手填；想发到自己的服务端，
把地址和 key 改掉即可。

**会发**

- 回测指标：收益率、年化、最大回撤、夏普、Sortino、Calmar、胜率、盈亏比、
  暴露度、交易天数/笔数、Beta/Alpha 等比例值
- 策略名与数值参数、程序版本号、事件时间
- 上传前按敏感键名再过滤一遍（`account`、`key`、`token`、`cash`、`balance` 等整键丢弃）

**不发**

- 持仓金额、账户号、券商信息、API key、密码、地址、手机号、身份证
- 自选股列表、K 线缓存、新闻阅读记录

**本地与删除**：开启后样本先写 `%LOCALAPPDATA%\ashare-quant\feedback\spool.jsonl`
（源码运行在仓库目录），上传成功才删；断网会攒着，上限 5000 条。关掉开关后
不再写队列、不再发包；删掉 `feedback/` 目录即可清空待上传样本。

**服务端**：默认指向作者维护的接收端，只做聚合统计和模型训练，不下发「买什么」。
内置 key 在服务端被限制成只能上传样本：拿它调模型、信号、先验接口一律 403，
即使 key 被公开也拿不到别的数据。想完全自建，改设置里的地址/key 即可，仓库不含服务端。

## 意见反馈

设置页 →「意见反馈」：写内容、可选联系方式，然后

- **保存到本地** → 追加到 `feedback/notes.jsonl`（源码运行在仓库目录，
  打包版在 `%LOCALAPPDATA%\ashare-quant`）
- **复制成 Issue 正文** → 拼好正文和环境信息（版本/系统/Python/Qt），
  直接粘到仓库 Issues
- **打开收件箱目录** → 自己翻

默认不联网、不上传。勾「附上版本与系统信息」也只带版本号、系统版本、
Python 与 Qt 版本，不带自选股、持仓、路径。

## 更新

设置页 →「更新」：把 GitHub 仓库链接粘进去，点「检查更新」。

- 支持 `https://github.com/用户名/仓库名`、带 `.git`、带 `/tree/main`、
  `git@github.com:...` 以及 `用户名/仓库名` 简写
- 优先读最新 release；没有 release 就退回最新的 tag，按版本号比较
- **下载并更新**（仅源码运行）：下 zip → 解压 → 程序退出后由脚本用
  robocopy 覆盖程序文件，自动重启。覆盖时排除 `.venv`、`.git`、`data`、
  `memory`、`config.json`、`*.db`，用户数据和配置不会被冲掉
- 打包版不做自替换，按钮会提示去发布页手动下载

GitHub API 在这类网络下常被证书链挡住，所以请求先走 requests、失败自动
退到系统 curl（走 Windows 证书存储）。

## 明确边界

- 只做多方向的研究工具，**不接券商、不同花顺、不发真单**；自动交易只在本机模拟盘上跑，不碰真钱。
- 模拟盘只在本机撮合（T+1、整手、佣金印花税与滑点），盈亏是练习数据，不是真实成交。
- 不提供加密货币行情或交易。
- 本地控制接口默认关闭，开了也只驱动模拟盘，且必须带 token。
- 默认不上传：数据与配置只留在本机；数据回流默认关闭，开启后只发脱敏样本。
- 回测与模拟盘结果只代表历史或练习，不构成投资建议；行情可能延迟或中断。
