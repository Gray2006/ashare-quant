# ashare-quant 量化工作台

本地运行的 A 股公开行情 + 技术分析 + 公司基本面 + 条件选股 + 回测桌面程序。PySide6 界面，数据存本机 SQLite，不需要账号。

**不含**：券商/同花顺下单、自动交易、加密货币、云端接口、任何投资建议。

## 功能

| 页面 | 做什么 |
|---|---|
| 行情 | 自选股实时报价、分时、K 线、资金流、新闻；右侧个股详情 |
| 多图 | 四图并排，十字线联动，同周期下标严格可比 |
| 板块 | 行业 / 概念 / 地域资金流榜，板块分时与成分股 |
| 龙虎榜 | 每日上榜个股、买卖席位明细、净买入排序 |
| 涨停 | 全市场当日涨停池、连板梯队、炸板/跌停与情绪分析 |
| 市场热点 | 情绪条、概念/行业涨幅榜、强势个股、热点快讯 |
| 全球市场 | 外盘（美股/港股/亚太/欧洲/商品/汇率）+ 国际新闻时政 |
| 资讯 | 快讯与本地档案合并，分类过滤，双击看原文 |
| 预警 | 价格上下穿、涨跌幅、量比条件预警，命中留痕 |
| 公司分析 | F10 概况、主营构成、财务趋势、估值同业、股东与事件 |
| 公司评估 | 财务/资金/舆论/产品/风险五维打分，可导出 Markdown/PDF |
| 选股 | 全市场快照 + 条件表达式筛选，内置预设 |
| 技术分析 | 缠论结构、道氏趋势、智能资金、背离、共振投票 |
| 形态 | 39 条 K 线形态，出现后的历史涨跌频率与超额 |
| 策略广场 | 内置策略、自定义规则、Pine Script 导入 |
| 回测 | 策略回测、净值曲线、8 项指标、交易明细、批量对比 |
| 大盘研判 | 趋势 / 广度 / 资金 / 外围 / 消息 五维打分 |
| 走势预判 | 未来 1/3/5/10/20 日涨/平/跌历史频率 + 因子贡献 |
| 涨幅预选 | 全市场快扫，每日候选与参考幅度 |
| 风险档位 | 横截面波动档位与建议仓位上限 |
| 数据健康 | 数据源状态、熔断明细、各领域数据新鲜度 |
| 设置 | 刷新间隔、数据目录、离线模式 |

## 安装运行

Windows，Python 3.10+（推荐 3.11/3.12）。

```bat
git clone https://github.com/Gray2006/ashare-quant.git
cd ashare-quant
pip install -r requirements.txt
python run.py
```

首次运行生成：

- `config.json`：自选股、刷新频率、界面设置
- `data/quantlab.db`：行情缓存与历史 K 线

源码运行时这两个文件在仓库目录；打包版在 `%LOCALAPPDATA%\ashare-quant`。可用环境变量 `GRAY_HOME` 指定独立目录。

自检：

```bat
python run.py --check      # 依赖与关键页面能否实例化
python run.py --smoke      # 真建主窗口逐页切换(offscreen 下可用)
```

## 数据来源

只抓公开网页行情，不登录、不缴费、不伪装来源：

- 东方财富：全市场快照、K 线、资金流、龙虎榜、板块
- 新浪：股票列表、部分行情回退
- 腾讯：日线 / 分时回退

接口随时可能变；抓不到时页面会显示数据源状态，不会拿假数据顶上。境外接口在部分网络下不可达，属正常。

## 明确边界

- 只做多方向的研究工具，**不接券商、不同花顺、不下单、不自动交易**。
- 不提供加密货币行情或交易。
- 不含云端上传：数据与配置只留在本机。
- 回测结果只代表历史，不构成投资建议；行情可能延迟或中断。
