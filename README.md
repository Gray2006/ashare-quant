# ashare-quant 量化工作台

本地运行的 A 股公开行情 + 技术分析 + 公司基本面 + 条件选股 + 回测桌面程序。PySide6 界面，数据存本机 SQLite，不需要账号。

**不含**：券商/同花顺下单、自动交易、加密货币、任何投资建议。数据回流默认关闭，开启后只上传脱敏后的回测/决策样本（见下文）。

## 一键安装（Windows，推荐）

1. 下载仓库 ZIP，解压到一个**普通目录**（不要放 `C:\Program Files`，那里没写权限）
2. 双击 `install.bat`
3. 等 1~3 分钟（第一次要下载 PySide6 等依赖）
4. 桌面出现「量化工作台」，双击就能用

要求：Windows 10/11，已装 Python 3.10+（安装时勾选 “Add python.exe to PATH”）。
不需要管理员权限；装完 `config.json`、`data/` 都在解压目录里，卸载或换机直接拷走。

- 启动：`start.bat`，或桌面快捷方式；想看报错用 `start.bat --console`
- 卸载：`uninstall.bat`（只删 `.venv` 和快捷方式，配置/缓存/待上传样本都保留）

## 手动安装（开发者）

```bat
git clone https://github.com/Gray2006/ashare-quant.git
cd ashare-quant
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py
```

首次运行生成：

- `config.json`：自选股、刷新频率、界面设置
- `data/quantlab.db`：行情缓存与历史 K 线

源码运行时这两个文件在仓库目录；打包版在 `%LOCALAPPDATA%\ashare-quant`。可用环境变量 `GRAY_HOME` 指定独立目录。

自检：

```bat
python run.py --check      # 依赖与关键页面能否实例化
python run.py --smoke      # 真建主窗口逐页切换(offscreen 下可用)
python tests/test_feedback_client.py   # 数据回流客户端(离线:脱敏/队列/地址校验)
```

## 数据来源

只抓公开网页行情，不登录、不缴费、不伪装来源：

- 东方财富：全市场快照、K 线、资金流、龙虎榜、板块
- 新浪：股票列表、部分行情回退
- 腾讯：日线 / 分时回退

接口随时可能变；抓不到时页面会显示数据源状态，不会拿假数据顶上。境外接口在部分网络下不可达，属正常。

## 数据安全

- **凭据字段**：config.json 里的接口密钥 / 本机 token 会加密落盘：Windows 用
  DPAPI（绑定当前用户），其他平台用 `.field.key` 的 Fernet 密钥（权限 600），
  程序读写时透明还原。加密后的值带 `dpapi1:` / `fernet1:` 前缀。
- **本地数据保险箱**：程序不运行时，可以把 `config.json` 与 `data/` 打包成
  一个 AES-256-GCM 加密的 `.vault` 文件：

  ```bat
  python tools/secure_data.py status
  python tools/secure_data.py encrypt
  python tools/secure_data.py decrypt vault/backup-xxxx.vault
  ```

  口令用 scrypt 派生，忘了就解不开。运行中的 SQLite 仍是明文（换 SQLCipher
  要换驱动、迁移库，风险大），所以保险箱是「关机 / 备份 / 带走」时用的。

## 数据回流（可选，默认关闭）

目的：把公开用户回测/决策里的**比例型结果**汇总起来训练模型，改善默认参数和因子权重。
没有账号系统，不需要登录。

**怎么开**：设置页 →「数据回流」→ 勾选。首次勾选会弹窗说明发什么、不发什么。
地址和 key 已内置（`cloud_defaults.json`），不用手填；想发到自己的服务端，
把地址和 key 改掉即可。

**会发**

- 回测指标：收益率、年化、最大回撤、夏普、Sortino、Calmar、胜率、盈亏比、
  暴露度、交易天数/笔数、Beta/Alpha 等比例值
- 策略名与数值参数、程序版本号、事件时间
- 上传前按敏感键名再过滤一遍（`account`、`key`、`token`、`cash`、`balance` 等整键丢弃）

**不发**

- 持仓金额、账户号、券商信息、API key、密码、地址、手机号、身份证
- 自选股列表、K 线缓存、新闻阅读记录

**本地与删除**：开启后样本先写 `%LOCALAPPDATA%\ashare-quant\feedback\spool.jsonl`
（源码运行在仓库目录），上传成功才删；断网会攒着，上限 5000 条。关掉开关后
不再写队列、不再发包；删掉 `feedback/` 目录即可清空待上传样本。

**服务端**：默认指向作者维护的接收端，只做聚合统计和模型训练，不下发「买什么」。
内置 key 在服务端被限制成只能上传样本：拿它调模型、信号、先验接口一律 403，
即使 key 被公开也拿不到别的数据。想完全自建，改设置里的地址/key 即可，仓库不含服务端。

## 明确边界

- 只做多方向的研究工具，**不接券商、不同花顺、不下单、不自动交易**。
- 不提供加密货币行情或交易。
- 默认不上传：数据与配置只留在本机；数据回流默认关闭，开启后只发脱敏样本。
- 回测结果只代表历史，不构成投资建议；行情可能延迟或中断。
