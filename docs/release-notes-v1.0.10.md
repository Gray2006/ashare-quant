这一版加了启动自动检查更新：打开软件后后台问一次 GitHub，有新版本才提醒。

## 新增

- **启动自动检查更新**：程序起来 8 秒后后台查一次，有新版本弹提示，
  点「去更新」直接跳到设置页看说明并下载。
- 一天最多查一次（记在 `config.json` 的 `update.last_check_day`），
  网络不通静默跳过，不打扰。
- 设置页原来的「检查更新」按钮保留，手动查随时可用。

## 说明

- 检查走 GitHub Releases API，失败自动退到 tags 兜底。
- 提醒只在有新版本时出现；已经是最新版本不弹窗。

## 边界

模拟盘与自动交易都只在本地撮合，**不接券商、不同花顺、不发真单**；
不含加密货币；模拟盈亏是练习数据，不构成投资建议。

## 安装

1. 下载 ZIP，解压到一个普通目录（别放 `C:\Program Files`）
2. 双击 `install.bat`，等 1~3 分钟
3. 桌面出现「量化工作台」

已经是 1.0.9 的话，设置页点「检查更新 → 下载并更新」即可，
`config.json`、`data/`（含模拟盘账本）、`.venv/` 都会保留。
