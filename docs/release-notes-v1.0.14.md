这一版把 1.0.13 之后的一批修复和新功能打进来，主要是复盘口径、策略归因和界面可用性。

## 修复

- **复盘当日盈亏**：昨日权益改用「昨日收盘价重算持仓市值」，不再拿快照里
  写快照那一刻的盘中价当基准（自动交易在 14:55 跑，会把昨天尾盘的涨跌算成今天的亏损）。
  今日快照缺失时用「现金 + 持仓现价」实时兜底，不再显示 `--`。
- **权益快照同步**：模拟盘每次落库时同时写 `sl_equity`，复盘页的基准不会停在旧值。
- **策略归因**：账户名对不上、样本不足提前返回、单例不刷新三个问题一起修，
  归因现在能正常出结论。
- **卖出碎单**：一次卖干净，不再留零星余额。
- **碎单连买 / 风控笔数上限失效**。
- **配置默认值硬编码**：改 `DEFAULTS` 不再白改。
- **凭证泄露防护**、安全提交工具（避免 `git add -A` 误提交）。

## 新增

- **策略归因**：跨策略比谁在赚钱，给出降权建议；`tools/learn_status.py`
  可以在命令行看某个账户的学习状态。
- **表格排序**：点表头排序；自选删股不再闪丢。
- **参数自适应** + 回撤闸行为测试。
- **单票当日买入次数上限**、全局限次。
- **待执行止损**：T+1 卖不掉的止损，第二天优先补执行。
- **组合回测加止损 + T+1 约束**。
- **5 分钟线**：每日维护补 5 分钟线，界面显示还差多少交易日。

## 研究结论（不影响使用，已写进 docs）

- 做 T 在 342 只样本上七组参数全负（t -0.5~-1.8），结论是不做。
- 止损档位回测与实盘结论相反，维持 `atr_mult=2.5`。
- 群体学习整体亏钱的根因是 T+1 让止损在买入当天无法执行。
- 因子挖掘选池偏差、组合回测前视偏差已修。

## 边界

模拟盘与自动交易都只在本地撮合，**不接券商、不同花顺、不发真单**；
不含加密货币；模拟盈亏是练习数据，不构成投资建议。

## 安装

1. 下载 ZIP，解压到一个普通目录（别放 `C:\Program Files`）
2. 双击 `install.bat`，等 1~3 分钟
3. 桌面出现「量化工作台」

或者最省事：下载
<https://raw.githubusercontent.com/Gray2006/ashare-quant/main/install-online.bat>
双击，自动拉最新版装到 `%USERPROFILE%\ashare-quant`。

已经是旧版本的话，设置页点「检查更新 → 下载并更新」即可，
`config.json`、`data/`（含模拟盘账本）、`.venv/` 都会保留。
