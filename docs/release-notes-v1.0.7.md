## 上一版（v1.0.6）回顾

v1.0.6 是第一个桌面版，修了双击启动失败、公司分析页「评估报告」不跳转、
导出按钮可能一直变灰三个问题，新增了意见反馈与 GitHub 自动更新。

## 安装

1. 下载 ZIP，解压到一个普通目录（别放 `C:\Program Files`）
2. 双击 `install.bat`，等 1~3 分钟
3. 桌面出现「量化工作台」

已经是 1.0.6 的话，直接在设置页点「检查更新 → 下载并更新」即可，
`config.json`、`data/`、`.venv/` 都会保留。
