这一版把「自动交易」页补回来了，模拟盘从手动下单变成可以定时跑策略调仓。
仍然只在本机模拟盘上跑，不接券商、不发真单。

## 新增

- **自动交易**：定时（默认 14:55~15:05）跑一次策略调仓，也可以点「立即执行」。
  选股 → 取现价 → 风控 → 模拟盘下单，全链路和手动下单同一套规则。
- **回撤闸**：账户回撤超过阈值时按配置减半仓或清仓，避免一路扛单。
- **动态仓位**：按近期波动自动缩放单票预算，波动大时少买。
- **分批建仓**：按强度分档买入，不一次打满。
- **止损止盈**：按比例或 ATR 触发，卖出走同一套风控。
- **全自动参数**：按波动与回撤自动算单票比例、止损止盈、回撤阈值，
  决策链和手动模式一致，便于对账。
- **今日学习报告**：自动交易页可直接看当天学了什么（决策、回填、参数变化）。
- **资金方案**：按账户现有资金算买几只、每只多少、首笔下多少。

## 说明

- 自动交易只走模拟盘，通道下拉只有「模拟盘」一项。
- 非交易时间不下单（网关层也会拒），避免收盘后往账本里塞单。
- 自动交易默认关闭，在「交易 → 自动交易」页手动打开。

## 边界

模拟盘与自动交易都只在本地撮合，**不接券商、不同花顺、不发真单**；
不含加密货币；模拟盈亏是练习数据，不构成投资建议。

## 安装

1. 下载 ZIP，解压到一个普通目录（别放 `C:\Program Files`）
2. 双击 `install.bat`，等 1~3 分钟
3. 桌面出现「量化工作台」

已经是 1.0.8 的话，设置页点「检查更新 → 下载并更新」即可，
`config.json`、`data/`（含模拟盘账本）、`.venv/` 都会保留。
