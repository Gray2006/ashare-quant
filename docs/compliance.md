# 合规取舍说明（中国法视角）

本文件记录公开版相对早期本地原型砍掉了什么、为什么砍、替代方案是什么。目的是让贡献者与使用者一眼看清边界，避免把高风险能力重新加回来。

> 以下是工程层面的风险控制说明，不构成法律意见。具体项目请咨询执业律师。

## 逐项处理

| 风险点 | 早期原型 | 公开版处理 | 理由 |
| --- | --- | --- | --- |
| 加密货币行情与交易 | 有 OKX 等接口 | **完全移除** | 境内对虚拟货币相关业务活动持禁止性监管态度，公开项目不应提供交易能力 |
| 自动/实盘交易 | 有调度、下单链路 | **完全移除**，只保留回测 | 未经许可从事证券经纪/投资咨询风险高；项目也不具备相应资质 |
| 同花顺客户端接入 | `pywinauto` 模拟点击下单 | **完全移除** | 绕过客户端正常使用方式，违反平台规则，且等同于自动交易 |
| 伪装 Referer 抓新浪 | 有 | **不使用新浪**，改用无需伪装的公开接口 | 规避访问控制可能违反平台条款与《网络安全法》相关要求 |
| 付费/登录数据（金十等） | 有 `x-app-id` | **完全移除** | 未授权抓取付费数据涉及著作权与合同风险 |
| 数据回流 | 上传交易/持仓事件 | **默认关闭，只发聚合指标**，显式同意，字段白名单 | 个人信息与交易数据敏感，遵循最小必要与告知同意 |
| 行情数据再分发 | 可能打包数据 | **不附带任何数据**，只提供抓取代码 | 行情数据版权归提供方，公开仓库再分发风险高 |
| 投资建议/荐股 | 部分文案 | **明确免责**，输出只称统计结果 | 无证券投资咨询资质，避免被认定为荐股 |
| 开源许可 | 不明确 | **MIT**，附免责声明 | 明确授权与责任边界 |

## 保留的能力

- 公开行情接口的**只读**访问（东方财富、腾讯），带限速、退避、熔断。
- 本地行情缓存、技术指标、因子计算、条件选股。
- 历史回测（T+1、整手、费用、涨跌停约束），**不接任何交易通道**。
- 本地只读仪表盘，仅监听 `127.0.0.1`。
- 可选、默认关闭、仅聚合指标的匿名数据回流。

## 贡献者红线

以下改动会被拒绝：

1. 新增券商、同花顺、期货、加密货币的下单或交易接口；
2. 新增需要登录、付费或绕过访问控制的数据源；
3. 默认开启数据回流，或上传代码、持仓、成交、账号、设备信息；
4. 在文案中给出买卖建议、收益承诺或"稳赚"类表述；
5. 把行情数据文件打包进仓库。
