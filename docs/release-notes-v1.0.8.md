这一版把模拟盘、复盘、学习三页补回来了，公开版从「只能看和回测」变成
「能下单练习、能盘后复盘」。

## 新增

- **模拟盘**：本地撮合，规则与回测一致（T+1、100 股整手、佣金/印花税/
  过户费/滑点）。支持多账户（默认账户 + 自建），每个账户独立现金、持仓、
  委托与净值曲线；持仓按行情实时重算市值与浮盈；可撤单、可重置。
- **复盘**：FIFO 配对算已实现盈亏，纪律检查（追高、过密下单、无退出条件的
  滞留持仓等），按标的与按日归因，当日盈亏含浮动。
- **学习**：自适应参数、今日日报、预测准确率回填；后台调度全天常驻，
  收盘后自动跑一轮。
- 选股页的「去下单」现在能用了：把代码、名称、价格带到模拟盘填单。

## 修复

- **模拟盘 T+1 在网关层失效**：风控层会拦当日买入卖出，但直接调用网关
  （脚本、以后接自动交易）能绕过去，当天买当天卖。现在 `SimGateway.place_order`
  自己再断言一次 `avail_qty`，绕不过。
- 主窗口的 `_learn_sched.stop()` 以前指向一个从没赋值的属性，退出时静默吞掉；
  现在调度器真的会启动也真的会停。

## 边界

模拟盘只在本地撮合，**不接券商、不同花顺、不发真单、不自动交易**；
不含加密货币；模拟盈亏是练习数据，不构成投资建议。

## 安装

1. 下载 ZIP，解压到一个普通目录（别放 `C:\Program Files`）
2. 双击 `install.bat`，等 1~3 分钟
3. 桌面出现「量化工作台」

已经是 1.0.7 的话，设置页点「检查更新 → 下载并更新」即可，
`config.json`、`data/`（含模拟盘账本）、`.venv/` 都会保留。
