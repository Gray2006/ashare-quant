这一版修了因子挖掘页「怎么用」按钮点了没反应的问题。

## 修复

- **「怎么用」按钮点不动**：帮助弹窗里用了 `txt.TextFormat.RichText`，
  PySide6 的 QLabel 实例没有 `TextFormat` 属性（枚举挂在 `Qt` 上），
  槽函数一进就抛 `AttributeError`。GUI 是 `pythonw` 启动的，stderr 不可见，
  表现就是「点了没反应」。改成 `Qt.TextFormat.RichText` 并补上 `Qt` 导入。

## 验证

- 离屏构造帮助弹窗：正常显示 680×560、标题「因子挖掘怎么用」。
- 其余按钮（回测这组因子 / 加入因子库 / 复制表达式 / 导出 JSON）的
  信号连接一并核对，未选中时都有「先选因子」提示，不是静默无响应。

## 安装

1. 下载 ZIP，解压到一个普通目录（别放 `C:\Program Files`）
2. 双击 `install.bat`，等 1~3 分钟
3. 桌面出现「量化工作台」

已经是 1.0.11 的话，设置页点「检查更新 → 下载并更新」即可，
`config.json`、`data/`（含模拟盘账本）、`.venv/` 都会保留。
